Storage (SSD / HDD)

Where Everything Lives Permanently.

Storage is your PC's long-term memory - it stores your operating system, games, applications, and files permanently even when powered off. The type and speed of your storage directly impacts how fast everything loads.

What It Does

When you launch a game, it reads gigabytes of assets (textures, models, audio, and level data) from storage into RAM. Fast NVMe SSDs do this in seconds, while slower HDDs can take much longer. The operating system also resides on storage, so a fast SSD dramatically improves boot times and application launch speeds.

How It Works

NVMe SSDs use NAND flash memory chips connected through an M.2 slot over PCIe lanes. Data is stored in memory cells that retain information even without power. HDDs use spinning magnetic platters with a moving read/write head - making them mechanical, slower, but much cheaper per gigabyte. SATA SSDs sit between the two, using the older SATA III interface, which is limited to around 550-600 MB/s.

Why It Matters for Gaming

With Microsoft DirectStorage technology, supported games can stream assets from fast NVMe SSDs much more efficiently, reducing CPU overhead and significantly decreasing loading times. However, DirectStorage does not completely bypass RAM, and games still rely on system memory. Games such as Forspoken showcase much faster loading and asset streaming on NVMe SSDs compared to HDDs.

Types & Variants

PCIe 4.0 NVMe SSD

Primary gaming and OS drive

Current mainstream standard. Up to around 7,450 MB/s sequential read speeds. Fits into an M.2 slot. Perfect for your operating system, games, and everyday use.

Pros:

  • Extremely fast
  • Silent
  • Compact M.2 form factor
  • Excellent value for gaming PCs

Cons:

  • More expensive per GB than HDDs
  • Lower write endurance than HDDs in extremely write-heavy workloads

PCIe 5.0 NVMe SSD

Future-proofing, professional workloads

Latest generation. Up to around 14,000 MB/s read speeds. Requires a motherboard with PCIe 5.0 M.2 support.

Pros:

  • Extremely high sequential speeds
  • Ready for future storage technologies
  • Excellent for professional workloads

Cons:

  • Very expensive
  • Runs hot (often requires a heatsink)
  • Minimal real-world gaming improvement over PCIe 4.0 currently

SATA SSD

Secondary storage, older systems

Uses the older SATA III interface, reaching around 500-550 MB/s. Still much faster than an HDD for everyday tasks.

Pros:

  • Affordable
  • Compatible with almost any modern PC
  • Still fast for operating systems and programs

Cons:

  • Much slower than NVMe SSDs
  • Limited by SATA III bandwidth
  • Less ideal for high-end gaming builds

HDD (Hard Disk Drive)

Bulk media storage, backups, and archives

Uses spinning magnetic platters. Typically delivers around 100-200 MB/s but offers the lowest cost per gigabyte and very large capacities.

Pros:

  • Cheap per GB
  • Huge capacities (20TB+)
  • Excellent for backups and media storage

Cons:

  • Very slow
  • Noisy
  • Fragile due to moving parts
  • Long game loading times

Key Specifications

Sequential Read/Write (MB/s)

Critical

Measures how quickly large continuous files can be read or written. PCIe 4.0 NVMe SSDs can reach around 7,450/6,900 MB/s. This mainly affects loading large files and transferring data.

Random 4K Read (IOPS)

Important

Measures performance when accessing thousands of small files. High IOPS improves operating system responsiveness and application loading.

Capacity (TB)

Critical

Modern AAA games commonly range from 50-150GB or more. A 2TB SSD can comfortably hold many modern games. Always consider future storage needs.

NAND Type (TLC/QLC)

Important

TLC (3 bits per cell) offers the best balance of speed, endurance, and price. QLC (4 bits per cell) is cheaper but generally has lower endurance and slower sustained write performance.

DRAM Cache

Important

SSDs with a DRAM cache maintain more consistent performance during large file transfers. DRAMless SSDs may slow down once their cache becomes full, especially under sustained workloads.

TBW Endurance

Nice to Know

TBW (Total Bytes Written) estimates how much data an SSD can write before reaching its rated lifespan. Around 600 TBW for a 1TB SSD is more than sufficient for typical gaming use.

Real-World Gaming Impact

Game Load Times

NVMe SSDs can load games significantly faster than HDDs. Many modern games load in just a few seconds on an NVMe SSD compared to much longer loading times on a hard drive.

2-10 sec vs 30-60+ sec on HDD

Open-World Streaming

Fast storage helps games stream textures and world data more smoothly, reducing loading pauses and texture pop-in in large open-world games.

Improves texture streaming performance

DirectStorage

Games that support Microsoft DirectStorage can stream assets more efficiently from NVMe SSDs, reducing CPU workload and improving loading performance.

Faster asset loading and decompression

Windows Boot Time

An NVMe SSD can boot Windows 11 in around 8-15 seconds, while an HDD typically takes 45-90 seconds.

10 sec NVMe vs 60 sec HDD

Common Mistakes

  • Installing games on an HDD while having an NVMe SSD - always install frequently played games on the fastest drive.
  • Buying a DRAMless SSD for the operating system without checking performance reviews.
  • Not buying enough storage capacity - modern games fill drives much faster than expected.
  • Ignoring cooling for high-performance PCIe 5.0 SSDs.

Fun Facts

  • The Samsung 990 Pro can read at around 7,450 MB/s - enough to transfer roughly 50 GB of data in about 7 seconds.
  • NVMe stands for Non-Volatile Memory Express - "Express" refers to the high-speed PCIe interface it uses.
  • Modern SSDs have no moving parts, making them faster, quieter, and more durable than HDDs.
