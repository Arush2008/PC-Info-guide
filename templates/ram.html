RAM

Random Access Memory

Your PC's Working Memory.

RAM acts as the fast, temporary workspace your CPU uses to store data it's actively working with. Think of it as a large desk - the bigger the desk, the more information your CPU can access at once without constantly retrieving data from slower storage.

What It Does

When you launch a game, it loads assets such as textures, models, scripts, and audio from your SSD into RAM so the CPU and GPU can access them much faster than reading directly from storage. RAM stores this data temporarily while your PC is running, clearing it when the system is powered off.

How It Works

RAM consists of billions of tiny memory cells that store data electronically. The memory controller (built into modern CPUs) communicates with the RAM by selecting rows and columns of memory cells to read or write data. DDR (Double Data Rate) memory transfers data on both the rising and falling edges of each clock cycle, effectively doubling data transfers per clock. JEDEC defines standard memory specifications, while XMP (Intel) and EXPO (AMD) profiles allow compatible memory kits to run at their advertised speeds.

Why It Matters for Gaming

If your PC runs out of available RAM, Windows begins using the page file on your SSD as virtual memory, which is much slower and can cause stuttering. Today, 16GB is considered the minimum for modern gaming, while 32GB is the recommended capacity for gaming and multitasking. RAM capacity generally has a bigger impact than RAM speed, but using the wrong DDR generation makes the system incompatible.

Types & Variants

DDR4

Budget builds, older platforms

Previous-generation memory that is still widely used. Common speeds range from 2133 MHz to around 3600 MHz, with enthusiast kits reaching over 5000 MHz. Supported on older Intel platforms and AMD AM4.

Pros:

  • Cheaper
  • Wide platform support
  • Excellent value for older systems

Cons:

  • Lower bandwidth than DDR5
  • Older technology
  • Not supported on AMD AM5 platforms

DDR5

Modern gaming builds, production workloads

Current-generation memory offering significantly higher bandwidth than DDR4. Standard speeds begin at 4800 MT/s, with enthusiast kits exceeding 8000 MT/s. Required on AMD AM5 platforms and supported on modern Intel DDR5 motherboards.

Pros:

  • Higher bandwidth
  • Better for multitasking and productivity
  • More future-proof
  • On-die error correction improves reliability

Cons:

  • More expensive
  • Generally higher latency numbers than DDR4
  • Requires a DDR5-compatible motherboard

Key Specifications

Capacity (GB)

Critical

16GB is the minimum recommended for modern gaming. 32GB is the sweet spot for gaming, streaming, and multitasking. 64GB or more is mainly useful for professional workloads like video editing, 3D rendering, and virtual machines.

Speed (MT/s)

Important

Memory speed determines how much data RAM can transfer each second. DDR5-6000 is widely considered the sweet spot for AMD Ryzen 7000 series, while Intel platforms generally benefit less from higher memory speeds.

CAS Latency (CL)

Important

CAS Latency measures how many clock cycles RAM waits before returning requested data. Lower latency generally improves responsiveness, although both speed and latency should be considered together.

Dual Channel

Critical

Installing two matching RAM sticks in the correct motherboard slots enables dual-channel mode, doubling available memory bandwidth compared to a single stick. Always check your motherboard manual for the recommended slot configuration.

XMP / EXPO Profile

Important

Most high-speed memory kits require XMP (Intel) or EXPO (AMD) to be enabled in the BIOS to run at their advertised speeds. Otherwise, they operate at standard JEDEC speeds.

Voltage

Nice to Know

DDR5 memory operates at a default voltage of around 1.1V. Higher-speed kits often require around 1.25-1.4V when using XMP or EXPO profiles, producing slightly more heat.

Real-World Gaming Impact

Gaming with 8GB vs 16GB

Modern games can easily exceed 8GB of memory usage, causing Windows to rely on the page file and resulting in noticeable stuttering. Upgrading to 16GB greatly improves overall gaming smoothness.

Much smoother gameplay and fewer stutters

Ryzen 7000 with DDR5-6000

AMD Ryzen 7000 processors generally achieve their best gaming performance around DDR5-6000 memory due to the balance between memory speed and Infinity Fabric performance.

Often among the best gaming performance for Ryzen 7000

Single vs Dual Channel

Using a single RAM stick reduces available memory bandwidth compared to dual-channel memory, which can noticeably reduce performance in memory-sensitive games and applications.

Up to 20-25% performance difference in some workloads

RAM Speed in Content Creation

Applications such as Blender, Premiere Pro, Photoshop, and other professional software often benefit from faster memory and higher memory capacity.

Can improve performance in memory-intensive workloads

Common Mistakes

  • Using a single RAM stick instead of two, reducing memory bandwidth by disabling dual-channel mode.
  • Not enabling XMP/EXPO, causing high-speed RAM to run at slower default JEDEC speeds.
  • Buying 64GB or more purely for gaming when 32GB is already sufficient for most users.
  • Mixing different RAM kits, which can sometimes reduce stability or prevent rated speeds.

Fun Facts

  • Modern DDR5-8000 memory can deliver over 64 GB/s of bandwidth per memory channel.
  • RAM is called volatile memory because it loses all stored data as soon as power is removed.
